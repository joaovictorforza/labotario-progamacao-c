# Laboratório de Programação em C

Repositório com as atividades das aulas 14, 15, 16, 17, 18, 21 e 22.

## Organização

Cada pasta contém os exercícios da aula correspondente. Os arquivos `.c` podem ser compilados individualmente.

## Como compilar e executar

Com GCC instalado, abra o terminal na pasta do exercício e execute:

```bash
gcc nome-do-arquivo.c -o programa
./programa
```

No Windows, depois da compilação, execute `programa.exe`.

## Observações

- Os programas foram separados por questão para facilitar a correção.
- Nas atividades de matrizes da Aula 15, a atividade de reserva de assentos usa uma matriz inicializada no código, conforme o enunciado.
- Na Aula 16, as questões conceituais 6 a 8 são respondidas no arquivo `respostas-revisao.md`.
- Os arquivos criados pela Aula 21 (`funcionarios.txt` e `numeros.txt`) aparecem no diretório de execução do programa.
